# postlang

Минималистичный экспериментальный парсер/транслятор для постфиксного языка, преобразующий входной текст в вложенные кортежи.

## Описание

`postlang` читает символы из стандартного ввода (`stdin`) и прогоняет их через цепочку парсеров:

- разбивает поток на слова по пробельным символам;
- группирует слова в кортежи по запятым;
- поддерживает вложенность через пустые группы (последовательные запятые).

Результат выводится в стандартный вывод (`stdout`) как вложенная структура Python (списки/кортежи).

## Требования

- Python >= 3.8
- (опционально) `uv` для управления зависимостями

## Установка

Проект не требует внешних зависимостей. Достаточно склонировать репозиторий и запустить скрипт.

```bash
git clone <url>
cd postlang
python postlang.py
```

Если вы используете `uv`:

```bash
uv run postlang.py
```

## Использование

Запустите скрипт и вводите текст. Для завершения ввода используйте:

- Windows: `Ctrl+Z`, затем `Enter`
- UNIX-like: `Ctrl+D`

Пример:

```bash
echo "a b , c , , d" | python postlang.py
```

Вывод:

```python
[ (('a', 'b'), ('c',)), ('d',) ]
```

> Примечание: скрипт перед чтением выводит подсказку `Enter Ctrl + Z and Enter on WIndows or Ctrl + D on UNIX-like to send EOF`. При перенаправлении ввода эта строка также попадёт в stdout.

## Синтаксис

- Слова разделяются пробелами и переводами строк.
- Запятая `,` завершает текущую группу слов, превращая её в кортеж.
- Две запятые подряд `,,` создают пустую группу, которая группирует все предыдущие группы в один вложенный кортеж.

Примеры:

| Ввод                | Вывод                              |
|---------------------|------------------------------------|
| `a b ,`             | `[('a', 'b')]`                     |
| `a b , c ,`         | `[('a', 'b'), ('c',)]`             |
| `a b , c , , d`     | `[ (('a', 'b'), ('c',)), ('d',) ]` |
